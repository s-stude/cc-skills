# Find Docs

This skill helps you find documentation about a library or a framework or a function in npm, web, official websites, api, or other developer ecosystem.

## When to Use This Skill

Use this skill when the user:

- Asks "how do I do X" where X might be smth. related to a library or a framework and a certain task, or implementation
- Says "find a documentation for X"
- Asks "can you do X" where X is a specialized capability

## How to Use this Skill

1. First, use Contex7 skill to look for documentation 
2. Do Web Search to look up official websites, documentation, etc. 
3. Do npm look up to find the library and its documentation
4. Look at node_modules (if exist) for library source code and go over it
